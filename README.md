# Polarization-CBW Team Workspace

This repository is the durable team workspace for the polarization manuscript and related measurement support work.

Current operating doctrine:

- Keep `polarization` as the headline concept.
- Treat `CBW` as an operationalization or measurement support layer, not the headline identity.
- Run bounded, supervisor-gated rounds when substantive manuscript work begins.
- Store durable team memory in `03_memory/` as graph-linked JSON records.

Top-level layout:

- `00_protocol/`: team charter and session-start rules
- `01_admin/`: roster, collaboration protocol, and schema versioning
- `02_projects/`: active project space plus reusable template
- `03_memory/`: canonical graph-based memory and event history
- `04_meetings/`: cross-project meetings
- `05_outputs/`: shared exports and handoff artifacts
- `06_archive/`: inactive or retired materials
- `team-memory/` and `meeting-logs/`: compatibility layers for older habits
